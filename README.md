## 三、個人回答

### 問題一：測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？直接把字串拆成 list，和再轉成 set，各自保留了什麼、失去了什麼？

- **為什麼桌遊費用以 3 人計算**：整理後的桌遊串列為 `['amy', 'ben', 'amy', 'cora']` 共 4 筆，但其中 `'amy'` 重複出現兩次。依規定同一人在同一場活動只算一位參加者且只收一次費用，去重後實際參加者為 `amy`、`ben`、`cora` 共 3 人，所以桌遊應收為 `3 × 120 = 360.00` 元。
- **`list` 與 `set` 各自保留與失去了什麼**：
  - 直接拆成 `list` **保留了**原本的出現順序與重複項目（能看出誰重複報名），但**失去了**自動排除重複元素的特性。
  - 再轉成 `set` **保留了**去重後的唯一成員，並可進行交集、聯集與差集比較；但**失去了**原本的先後順序與重複次數資訊。

### 問題二：測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。

- **集合關係說明**：測試三中桌遊去重集合 $B = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$ 與電影去重集合 $M = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$ 完全相同。因此聯集 $B \cup M$ 的元素個數（總不重複人數）為 $|B \cup M| = 3$ 人，交集 $B \cap M$ 的元素個數（共同人數）也是 $|B \cap M| = 3$ 人，而兩個方向的差集 $B - M$ 與 $M - B$ 皆為空集合（顯示為 `[]`）。
- **算式說明**：
  - 「總不重複人數」為至少參加一場的人數（聯集大小）：$3$ 人。
  - 「報名人次」為兩場去重人數相加：$|B| + |M| = 3 + 3 = 6$ 人次。
  - 各場分別按去重人數計費，總應收為：$(3 \times 120) + (3 \times 80) = 360 + 240 = 600.00$ 元。
